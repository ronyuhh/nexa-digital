# Nexa Digital — Responsive Agency Website

A responsive digital agency landing page built with HTML, CSS, and JavaScript.

## Live Demo

https://ronyuhh.github.io/nexa-digital/

## Features

- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu
- Services, About, Portfolio, and Contact sections
- CSS-built portfolio previews
- Contact form integration with Formspree
- Dynamic footer year
- Accessible form labels and keyboard focus styles

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Run Locally

1. Clone this repository:
   `git clone https://github.com/ronyuhh/nexa-digital.git`
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open the file in your browser.

## Project Status

This is a learning and portfolio project. The Task Manager Dashboard and E-commerce Storefront shown in the portfolio are concept projects, not completed applications.

The contact form depends on its Formspree configuration and has not been verified unless a test submission succeeds.
